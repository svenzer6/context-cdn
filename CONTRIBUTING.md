# Contributing

Contributions are welcome.

Good contribution areas:

- Cleaner Markdown extraction strategies
- Tokenizer-aware budgeting implementations
- `ai-index.json` schema improvements
- Semantic topic graph design
- RSL / licensing integrations
- Example APIs and SDKs
- Real-world case studies

## How to contribute

1. Fork the repository.
2. Create a branch.
3. Make your changes.
4. Open a pull request with a clear explanation.
